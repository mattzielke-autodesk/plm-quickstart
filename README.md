# PLM Quick Start

An interactive guide to getting value from Autodesk Fusion Manage (PLM) fast. Work through it yourself at your own pace, or run it live in front of a room.

## ▶ Open the Quick Start

**https://mattzielke-autodesk.github.io/plm-quickstart/**

No install, no login, no download. Click the link and it runs in your browser.

## What this is

The Quick Start takes you from a new Fusion Manage tenant to a working setup, one short step at a time. Each screen shows the real product with numbered callouts that reveal one at a time.

It covers both editions of Fusion Manage:

- **Standalone**—the **Items & BOMs** chapter is for you. You bring items and bills of materials in by import from Vault, another PDM or spreadsheets, then set up workspaces, users, views and reports and check it all works.
- **Fusion connected**—the **Fusion ↔ Manage** chapter shows how designs in Fusion flow into Manage.
- **Both**—Change management, Quality, Ideas and Documents work in either edition.

## Quick start

1. Open the link above.
2. Press **F** for fullscreen.
3. Press **→** or **space** to advance.
4. Stuck? Press **?** for the shortcut list at any time.

To read at your own pace, press **P** to switch from Present to Explore mode. The whole guide becomes one scrollable page with a table of contents.

## Requirements

| | |
|---|---|
| Browser | Any current Chrome, Edge, Firefox or Safari |
| Install | None |
| Account / login | None |
| Internet | Only to load the page the first time |
| Screen | Designed for a 16:9 projector or laptop; works on tablet |

The guide is a single self-contained HTML file. Every image and style is embedded—nothing is fetched from a CDN. Once the page has loaded, it keeps working with the network off.

Some links inside the content need internet when clicked, such as the Autodesk Help pages (help.autodesk.com).

## Running it offline

1. Download the file: [index.html](https://github.com/mattzielke-autodesk/plm-quickstart/raw/main/index.html) (about 21 MB; right-click → Save link as…).
2. Double-click the saved file. It opens in your default browser and runs identically.

No web server is needed—`file://` works fine.

## Navigating

### Toolbar

| Control | What it does |
|---|---|
| ☰ | Chapter menu—jump to any section |
| ⌂ | Back to the cover |
| ← → | Back / forward |
| Notes | Show the notes for the current screen |
| Basic / Advanced | Toggle the depth of the content |
| Present / Explore | Toggle slide mode and scrollable-page mode |
| ? | Shortcut list |
| ⛶ | Fullscreen |

The pill next to the screen count shows which edition the current chapter applies to: **Standalone**, **Fusion connected** or **Both editions**.

### Keyboard shortcuts

| Key | Action |
|---|---|
| → / space / PageDown | Next—also reveals callouts one at a time |
| ← / PageUp | Back |
| S | Notes |
| P | Present / Explore mode |
| A | Basic / Advanced mode |
| F | Fullscreen |
| H | Jump to cover |
| M | Chapter menu |
| Esc | Close menu, notes or an enlarged image |

Click any screenshot to enlarge it. Esc closes it.

**Note on →:** screens reveal their callouts progressively. If a slide looks like it isn't advancing, it is—you're stepping through the annotations on that screen before moving to the next one.
